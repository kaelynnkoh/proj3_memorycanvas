# 🌌 Memories in the Sky

An interactive web experience that simulates a peaceful stargazing date under a night sky. Click on constellations to reveal sweet memories and personalized messages.

## ✨ Features

- Interactive starry night sky built with HTML5 Canvas
- Clickable constellations that display romantic or nostalgic messages
- Customizable messages for a personal touch

## 💡 How to Use

1. Clone or download the project files.
2. Open `index.html` in your browser.
3. Click on glowing constellation points to discover hidden messages.

## 🛠 Customization

To personalize:

- **Messages:** Update the `constellations` array in the `<script>` section with your own coordinates and messages.
- **Stars:** Adjust the number of stars or their brightness in the `createStars()` function.
- **Design:** Modify the CSS for colors, font styles, or add animations.
